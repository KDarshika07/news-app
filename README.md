# News App

An AI-powered news application that helps users understand how current events affect their daily lives.

## Features

- Fetch latest news
- AI-powered summaries
- Personalized insights
- Multiple news categories
- FastAPI backend
- React frontend (planned)

## Tech Stack

- Python
- FastAPI
- NewsData.io API
- Google Gemini / OpenAI
- React
- Git & GitHub
